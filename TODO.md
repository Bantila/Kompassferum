## Не проверено на живой платформе

- [ ] **MAX целиком.** Вход в мини-приложение и разбор событий бота написаны по
      документации dev.max.ru, доступа к платформе нет. Подпись `initData`
      проверяется тем же алгоритмом, что и в Telegram (HMAC-SHA256 с ключом
      «WebAppData»), покрыта тестами — но первый реальный запуск может вскрыть
      расхождения. Отладка идёт на Telegram.
- [ ] **Подпись вебхука MAX.** Сейчас прямое сравнение секрета из заголовка
      `X-Max-Bot-Api-Secret`: по документации платформа возвращает значение,
      заданное при подписке, а не HMAC от тела. Если окажется иначе — считать
      `hmac.new(secret, body).hexdigest()`.
- [ ] **GigaChat ни разу не ответил вживую.** Код и схема написаны, тесты идут
      на моках. Сбер подписан НУЦ Минцифры, сертификаты которого решено не
      ставить на рабочую машину, поэтому проверка шла только через запасной
      алгоритм. Нужен один реальный прогон на сервере: убедиться, что
      `with_structured_output(method="json_schema", strict=True)` отдаёт ровно
      пять профессий и не падает на длинном ответе.

## Безопасность и приватность

- [ ] **Роль педагога никем не подтверждается.** Сводка по классу отдаётся
      любому пользователю с `role=teacher`, связь «педагог ↔ его класс» не
      проверяется. Для пилота в школе нужен хотя бы код приглашения от
      администратора.
- [ ] **CORS открыт для всех origin** (`allow_origins=["*"]` в `app/main.py`) —
      до тех пор, пока не известен домен мини-приложения MAX. Сузить, как только
      появится.
- [ ] **Нет ограничения частоты запросов.** Ни на вход, ни на `/api/tests/submit`,
      ни на вебхук. Один скрипт может забить базу прохождениями.
- [ ] **Согласия на обработку данных не хранятся.** Сводка ограничена
      k-анонимностью (не формируется, пока тест не прошли хотя бы 3 ученика),
      но реестра согласий нет. Для реальной школы это обязательное условие.

## Качество оценки

- [ ] **Банк мал: 3 задачи на предмет.** Для устойчивой оценки нужен пул
      побольше с ротацией, иначе ответы быстро разойдутся между учениками —
      особенно внутри одного класса.
- [ ] **Баллы разных попыток несравнимы между собой.** Сложность в скоринге не
      участвует — балл это доля верных ответов. Со второй попытки задачи труднее
      (`medium`+`hard`), поэтому падение балла может означать не «стал хуже», а
      «тест стал сложнее». История прохождений этого пока не поясняет: либо
      выводить пару сложностей рядом с результатом, либо взвешивать балл по
      сложности.
- [ ] **Пороги антифрода — эвристика.** `MIN_SECONDS_KNOWLEDGE = 3.0`,
      `RUSHED_SHARE = 0.4` и остальные подобраны из здравого смысла, а не из
      данных. Когда наберётся хотя бы сотня реальных прохождений — сверить и
      поправить, иначе честные быстрые ученики будут попадать в «недоверие».
- [ ] **Адаптивный подбор не проверялся на людях.** Модель выбирает пять
      предметов по блоку A; насколько выбор осмысленный, видно только на живых
      прохождениях.
